# TaskFlow

A modern and responsive task management application built with HTML, CSS, and JavaScript.

TaskFlow helps users organize tasks, set priorities and due dates, track productivity, and manage completed work through a clean and professional interface.

## 🚀 Live Demo

https://abdul306.github.io/task-management-app/

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- High, medium, and low priority levels
- Set due dates
- Automatic overdue detection
- Search tasks
- Filter tasks by All, Active, and Completed
- Clear all completed tasks
- Productivity statistics
- Completion percentage
- Light and dark mode
- Tasks saved using Local Storage
- Responsive design for desktop, tablet, and mobile

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- GitHub Pages

## 📱 Responsive Design

TaskFlow is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

## 📊 Productivity Tracking

The application provides a quick overview of:

- Total tasks
- Completed tasks
- Active tasks
- Completion rate
